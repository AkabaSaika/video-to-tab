首个可直接运行的版本：从吉他演奏视频中提取 tab 谱，去掉播放光标，拼接成完整的长图 / PDF。

## 下载

| 系统 | 文件 |
|---|---|
| Windows 10/11 (x64) | `video-to-tab-v0.01-windows-x64.zip` |
| macOS (Apple Silicon) | `video-to-tab-v0.01-macos-arm64.zip` |
| Linux (x64，glibc ≥ 2.35) | `video-to-tab-v0.01-linux-x64.zip` |

解压后运行其中的 `video-to-tab`（Windows 为 `video-to-tab.exe`），会自动打开浏览器。无需安装 Python、Node 或 ffmpeg。详见压缩包内的 README.txt。

## 功能
- 输入本地视频（mp4 / mkv / webm / mov / avi / flv …）或 bilibili / YouTube 链接、BV 号
- 自动定位谱面区域，可手动框选调整
- 自动识别换页，时间中值去除播放光标，合并重复页并标注重复段落
- 分段横向滚动的谱面自动拼接去重，并按小节重新排行
- 校对页面（排序、删除），导出 PNG 长图 / A4 PDF

## 已知限制
- 当前小节的高亮底色会保留在输出中
- 低分辨率视频（约 450p 以下）的滚动拼接可能出错
- B 站视频可能需要 cookies（把 cookies.txt 放在程序旁边）
- 程序未签名：macOS 首次运行需在“隐私与安全性”中允许；Windows 可能出现 SmartScreen 提示，选择“仍要运行”
