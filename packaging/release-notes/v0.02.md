在 v0.01"截图拼接"的基础上，新增**识谱**：把视频里的 tab 谱识别成可编辑的乐谱，并导出 Guitar Pro 文件。

## 下载

| 系统 | 文件 |
|---|---|
| Windows 10/11 (x64) | `video-to-tab-v0.02-windows-x64.zip` |
| macOS (Apple Silicon) | `video-to-tab-v0.02-macos-arm64.zip` |
| Linux (x64，glibc ≥ 2.35) | `video-to-tab-v0.02-linux-x64.zip` |

解压后运行其中的 `video-to-tab`（Windows 为 `video-to-tab.exe`），会自动打开浏览器，无需安装任何依赖。

## 新功能
- **识谱**：在校对页点"识谱"，识别出每一拍的弦、品格、休止和时值（符干、横梁、附点、三连音），小节编号与原谱一致。
- **多声部**：一行里有多个谱表（如 Gt.1 + Gt.2）时，每个谱表识别为一个声部。
- **延音**：识别切分延音（只有符干的后续拍）、括号里的延音音符 `(14)`，以及跨小节线的延音。
- **演奏技巧**：推弦（½ / full 等）、滑音、顿音、击勾弦、闷音 P.M.、泛音、颤音。
- **识谱编辑器**：用 alphaTab 渲染乐谱，低置信度的拍用橙色标出；点击任意一拍，对照原图片段修改品格、时值、延音和技巧；修改自动保存，刷新页面或重启程序后可以继续编辑。
- **导出 .gp**：导出 Guitar Pro 7/8 文件，包含所有声部、延音和技巧。
- **分段滚动的谱面**：自动拼接去重，并按小节重新排行。

## 已知限制
- 识谱主要针对 Guitar Pro 渲染的谱面做了验证；其他软件的谱面效果未知。
- 不读取拍号（一律按 4/4）和速度标记（默认 120，可在识谱页修改）。
- 线距小于约 14 像素的低清视频准确率会明显下降。
- 颤音、推弦后回落只在合成数据上测试过；¼ 推弦会识别为 ½；泛音只区分自然 / 人工。
- 不支持装饰音、预推弦、幽灵音；跨小节线的滑音线识别不到。
- 当前小节的黄色高亮会保留在导出的 PNG / PDF 中。
- 程序未签名：macOS 首次运行需在"隐私与安全性"中允许；Windows 可能出现 SmartScreen 提示，选择"仍要运行"。
