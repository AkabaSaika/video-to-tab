# 分段滚动谱面：重叠拼接与按小节重排

## Context
有些吉他视频的 tab 谱是"分段横向滚动"的（Songsterr 风格）：每次向左跳一段，相邻两页之间有约一小节的重叠。v1 把每个稳定段当作一页直接堆叠，结果相邻页重复出现同一段内容（真实视频 b：23 页，每页都和上一页重叠约 500 px）。

用户最初的想法是识别小节号来去重。但在真实数据上，重叠区域里后一页往往看不到小节号：视频 b 第 2 页左侧是完整的第 6 小节，可它的小节线和小节号恰好在画面外。所以改为**图像水平对齐**。这个方案已在视频 b 上验证：相邻页位移稳定在约 1175 px；拼接接缝正确；重排后第 1–34 小节连续，没有重复。

## 决策
- 用图像水平对齐来去重，不做 OCR，也不新增依赖。
- 拼成横向长图后，按小节线切成小节，再按原页面宽度逐行重排，每行不拆开小节。
- `Page` 数据结构、API、前端、导出都不改。

## 设计

### 位置
`pipeline.analyze()` 的顺序改为：
1. 过滤掉没有谱线的页
2. `merge_adjacent`
3. **`stitch_pages`**（新增）
4. `mark_repeats`

新模块 `backend/app/stitch.py`。

### 重叠检测
- 先转灰度。灰度中位数 < 128 的深色主题先反相（255 − 灰度），统一成浅底深墨迹。
- 把页面转成墨迹掩码：灰度 < 140。白底和黄色高亮（灰度约 230）都当作背景。然后**去掉谱线和小节线**：用 41×1 的水平开运算找出谱线、用 1×41 的竖直开运算找出小节线等竖线，再都减掉。谱线在任何位移下都能对上，不去掉的话，合成的整页切换页面也会得 0.7 分；小节宽度均匀时，小节线在小节宽度的整数倍位移处也会对上（合成整页切换页面得 0.38–0.79 分），都会被误判为重叠而丢小节。
- `overlap_shift(a, b) -> (shift, score)`：两页必须同尺寸。在 `s ∈ [MIN_SHIFT=50, W - MIN_OVERLAP=200)` 范围内求 `IoU(a[:, s:], b[:, :W-s])`，取最大值。
- **峰值余量**：再求离最佳位移超过 `PEAK_EXCLUSION = 40` px 的位移中的最高分（次峰）。最佳分减次峰分 < `PEAK_MARGIN = 0.15` 时，score 记为 0。重复的 riff 跨过翻页时，几个位移都能对上，分不清真实位移，这时宁可不拼。
- `score ≥ OVERLAP_THRESHOLD = 0.35` 判定为滚动重叠。去掉谱线和小节线后实测：视频 b 为 0.73–0.90，峰值余量最小 0.33（第 1 对，次峰 0.43）；视频 a ≤ 0.09；合成的整页切换 ≤ 0.22。

### 分组与拼接
- 依次比较相邻页：重叠就并入当前组，否则另起一组。
- 只有 1 页的组原样输出，因此整页切换的视频行为和 v1 完全一致。
- 多页组拼成长图：依次取每页 `[:, :shift_i]`，最后一页取全部。

### 小节线
- 在长图上用 `region.detect_staves` 找到谱表。选线数最多的那个谱表（也就是 tab 谱，同时有五线谱时也不会选错），取它的最上和最下谱线 [top, bottom]。
- 一列在 [top, bottom] 之间的暗像素（灰度 < 140）覆盖率 ≥ 0.9 就算小节线。
- 相邻小节线间距 ≤ 12 px 的合并成一条（处理双小节线、终止线），取最左一列作为位置，这样切点落在两道竖线左侧，不会把双小节线拆到两行。
- 找谱表前同样先按上面的规则把深色主题反相，避免把谱线之间的空隙当成谱线。

### 重排
- 按小节线把长图切成若干段：第一条小节线之前、每两条小节线之间、最后一条小节线之后，各算一段。
- 按目标宽度（原页面宽度）逐行贪心装填，每行不拆开一段。单段比目标宽度还宽时独占一行。
- 行高等于长图高度，行宽保持实际宽度，不补白：导出时会统一补齐。之前补白导致短的末行因谱线覆盖率不够，检测不到谱表。每个切点取小节线左侧 3 px，这样每个小节都以自己的小节线开头。离长图两端不到 6 px 的切点忽略，避免切出几像素宽的碎行。
- 每一行是一个新的 `Page`：start 取它覆盖的源页面中最早的开始时间，end 取最晚的结束时间。
- 覆盖关系按"段在长图中的 x 范围"映射回源页面：拼接时记录每个源页面贡献的 x 区间。

### 退路
- 长图上找不到谱表或小节线时，按目标宽度直接切段。
- 分组逻辑本身已保证只有得分达标的重叠才会拼接。

## 测试
- **合成：** `tests/synth.py` 新增分段滚动生成器。先画一条包含 N 个小节的长谱（每个小节带小节线、数字，部分小节带黄色高亮），然后每页平移固定步长，相邻页之间留约 1/3 重叠。断言：
  - 分组正确
  - 拼接位移误差 ≤ 3 px
  - 重排后的小节数等于 N，且没有重复小节
  - 原有的整页切换合成视频结果不变（现有测试保持通过）
- **真实：** 用视频 b 跑 CLI 冒烟。期望输出行数远少于 23，小节连续，不重复。

## 已知限制
- 重排后行的时间范围会相互重叠；重复段检测只在行宽完全相同的情况下生效。
- 滚动谱面里如果重叠区域恰好是重复的 riff，峰值余量不够，这两页不会拼接，会按原样输出（内容重复，但不丢小节）。

## 不在范围内
去除黄色高亮、OCR 小节号、连续平滑滚动的谱面。
